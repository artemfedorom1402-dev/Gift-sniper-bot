## 🔍 Если что-то не работает

1. **Ошибка 403 Cloudflare** → нужен прокси (PROXY_URL). Без него Tonnel блокирует IP Railway.
2. **Ошибка 503 от прокси** → проверь личный кабинет proxys.world — может быть, закончился трафик или сессия.
3. **Бот не отправляет алерты** → нажми "🔍 Проверить" на любой слежке — там будет подробный отчёт, почему ничего не пришло.
4. **Другие ошибки** → посмотри логи Railway (Deployments → View Logs).
