# Gift Sniper Bot

Telegram-бот для мониторинга Tonnel NFT маркетплейса с алертами о низких ценах.

## 🔴 Исправление конфликта двойного запуска

Если видишь ошибку:
```
ERROR: Conflict: terminated by another bot instance is running
```

**Это исправлено в этой версии!** 

В коде добавлено удаление вебхука перед запуском поллинга, что предотвращает конфликт между старым и новым экземплярами бота.

## 🚀 Быстрый старт

### Локально
```bash
pip install -r requirements.txt
export BOT_TOKEN="твой_токен_от_BotFather"
python bot.py
```

### На Railway

1. Залей репо на GitHub
2. На railway.app создай новый проект из этого репо
3. Добавь переменную `BOT_TOKEN` в Variables
4. (Опционально) Добавь `PROXY_URL` если нужен прокси для Tonnel
5. Готово! Railway автоматически запустит бота

## 📋 Переменные окружения

| Переменная | Обязательна | Описание |
|-----------|------------|---------|
| `BOT_TOKEN` | ✅ Да | Токен от [@BotFather](https://t.me/BotFather) |
| `PROXY_URL` | ❌ Нет | Резидентский прокси (почти всегда нужен на Railway) |
| `PROXY_MAX_CONCURRENT_PER_ADDR` | ❌ Нет | Макс. одновременных запросов (по умолчанию 1) |
| `TONNEL_MAX_RETRIES` | ❌ Нет | Кол-во повторов при ошибке (по умолчанию 3) |
| `TONNEL_RETRY_DELAY_SECONDS` | ❌ Нет | Задержка между повторами (по умолчанию 1.5) |
| `POLL_INTERVAL_SECONDS` | ❌ Нет | Интервал проверки (по умолчанию 120) |

## 🛠️ Решение проблем

### Ошибка "Conflict: terminated by another bot instance"
→ Бот уже обновлён с исправлением. Просто сделай новый деплой на Railway.

### Ошибка 403 от Tonnel
→ Нужен прокси. Добавь `PROXY_URL` в Variables на Railway.

### Ошибка 503 от прокси
→ Проверь статус прокси-провайдера (может быть перегруз или нет трафика).
