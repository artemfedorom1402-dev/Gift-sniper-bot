# Исправления, сделанные в bot.py

## 1. Отключена saleHistory()
- Причина: authData для saleHistory() не документирован в tonnelmp, даже разработчик пакета не уверен, что туда вписывать
- Решение: функция теперь просто возвращает пустой список вместо попытки получить данные
- Эффект: бот не теряет времени на ошибку, основной функционал (сравнение с медианой и аукционы) остаётся работающим

## 2. Добавлена проверка TONNEL_AUTH_DATA в инициализацию
- Теперь переменная читается из окружения, но не используется (так как saleHistory() отключена)

## 3. Потенциальные улучшения безопасности
- Все user inputs (названия коллекций, цены) уже экранируются перед отправкой в Telegram (esc())
- Названия коллекций обрезаются по длине (truncate_utf8)
- Цены валидируются (должны быть > 0 и числовыми)

## 4. Обработка исключений
- poll_loop: все исключения ловятся в bounded_scan (строка 760)
- scan_collection: исключения при отправке сообщений ловятся отдельно для каждого алерта
- on_unhandled_error: глобальный перехватчик для неожиданных ошибок в хендлерах
- _call_tonnel_with_retries: корректная обработка таймаутов и повторов

## 5. Управление ресурсами
- asyncio.Semaphore используется для ограничения параллельности
- threading.Lock используется для безопасной ротации прокси
- list(tracked) используется при итерации, чтобы избежать race condition

## 6. Валидация и безопасность
- Есть проверка BOT_TOKEN перед запуском (строка 1059-1060)
- Есть warning если прокси не настроен (строка 1061-1066)
- Все динамические данные экранируются перед отправкой в Telegram
